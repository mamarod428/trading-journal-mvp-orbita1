# Órbita · Proyecto en JavaScript (Hito 1 de 5)

Preparación inicial del repositorio para el Hito 1: estructura base del proyecto, configuración de ESLint y planificación del trabajo.

## 1. Backlog (ordenado por prioridad)
1. **Preparación del proyecto:** Crear estructura de carpetas (`css/`, `js/`), `index.html`, configurar ESLint sin errores y redactar este `README.md`.
2. **Entidades de ejemplo (`datos.js`):** Definir y exportar las entidades relacionadas (`cuentas` y `sesiones`) con al menos 10 registros.
3. **Menú de navegación:** Implementar el menú superior enlazando las vistas previstas en el mapa de pantallas.
4. **Listado y calendario:** Generar desde JavaScript el calendario y el listado de sesiones a partir de los datos exportados, sin escribir los elementos a mano en el HTML.
5. **Detalle de sesión:** Mostrar los datos completos de la sesión seleccionada al pulsar sobre ella.

## 2. Mapa de pantallas
* **Dashboard:** Vista principal con resumen, calendario de días operados y bloque de gráfica.
* **Diario:** Sección enlazada en el menú para el registro diario.
* **Histórico:** Sección enlazada en el menú con el listado de sesiones y acceso a su detalle.
