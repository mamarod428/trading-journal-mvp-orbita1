# Trading Journal MVP — Diseñar para que funcione (Órbita 1)

Proyecto de Diseño de Interfaces WEB centrado en la investigación UX y conceptualización (Mobile First & Desktop) de un diario de trading interactivo con contención emocional y control de riesgo algorítmico.

## Entregables incluidos en esta fase
- Análisis de referentes y extracción de Insights.
- Definición de User Personas (Escritorio/Móvil).
- Arquitectura de la Información (Sitemap).
- User Flow con casos límite y divulgación progresiva.
- Prototipo funcional interactivo en escala de grises.
